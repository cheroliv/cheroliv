## 环境与工作站

### [`magic-stick`](https://github.com/cccp-education/magic-stick)

一个 Gradle Kotlin DSL 构建脚本，协调可启动的 Xubuntu ISO 的创建 — 同时作为 **live USB** 和 **安装程序**，配备三类用户所需的必要工具：

- **移动工作站** — 我完整的可移植环境在 U 盘上。
- **FTTH 电信技术员** — 准备好的现场工具。
- **学生/实习生** — 无需先前安装即可立即上手。

该项目体现了生态系统的理念：工作环境本身就是一个**可重现、版本化、文档化**的 artifacts。项目文档由 [`bakery`](https://github.com/cccp-education/bakery-gradle) 生成并发布在 [cccp.education/magic-stick](https://cccp.education/magic-stick/)上。
